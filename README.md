# Mikropsy Việt Nam

Website kiến thức tâm lý và tài nguyên thực hành.

## GitHub Pages
Đưa nội dung thư mục này lên nhánh main. Trong Settings → Pages, chọn Deploy from a branch → main → / (root).

## Đăng bài
Mở _posts, tạo file YYYY-MM-DD-ten-bai.md trên GitHub và sao chép phần thông tin đầu tệp từ một bài có sẵn. Đổi title, series, summary và nội dung. Dùng filter pedia, learning hoặc community để đưa bài vào đúng bộ lọc. Bấm Commit changes. Để đăng ảnh, tải ảnh vào assets rồi chèn bằng cú pháp Markdown với đường dẫn tương đối theo baseurl.
